# Page Designer component catalog

This is the canonical index of the custom Page Designer components kept on `main`. It covers both runtimes in this repository while keeping their deployment paths separate:

- **Storefront Next:** 36 custom component types, nine page types, three visual editors, React implementations, tests, and cartridge metadata.
- **SFRA:** one self-contained component package with ISML rendering, a visual color editor, a standalone Page Designer test page, and tests.

The count intentionally excludes the standard `Content.*` and `Layout.*` component types inherited from the Storefront Next template. For installation and merchant authoring details, use the [Storefront Next cartridge guide](../cartridges/plugin_sfnext_page_designer/README.md) or the [SFRA package guide](../sfra/two-column-image-cta/README.md).

## Explore the components

Run `pnpm storybook` from the repository root to open the available interactive Storefront Next examples. Each catalog entry also links directly to its implementation and Page Designer metadata, so components without a standalone story remain discoverable and documented.

The SFRA package is deliberately isolated from the Storefront Next generator and deployment commands. Deploy its `app_custom_pd_components` and `bm_custom_pd_components` cartridges using the instructions in the package guide.

## Related Page Designer building blocks

The Storefront Next cartridge also contains these nine page types:

- Blank landing page
- Product listing page
- Merchandising Product Listing page
- Product detail page
- Flexible Product Detail page
- Category Landing page
- Blog home
- Shared blog-post layout
- Branding Studio workspace

Its visual editors are [Theme Editor](../cartridges/plugin_sfnext_page_designer/cartridge/experience/editors/SFNextToolkit/themeEditor.json), [Shoppable Hotspots](../cartridges/plugin_sfnext_page_designer/cartridge/experience/editors/SFNextToolkit/shoppableHotspots.json), and [Motion Editor](../cartridges/plugin_sfnext_page_designer/cartridge/experience/editors/SFNextToolkit/motionEditor.json). The SFRA package provides its own [color picker](../sfra/two-column-image-cta/cartridges/bm_custom_pd_components/cartridge/experience/editors/custom_pd/colorpicker.json) and standalone test page.

## Maintenance rule

`main` is cumulative. New production-ready components should land with:

1. Their implementation and Page Designer metadata.
2. Tests and an interactive story or preview fixture when practical.
3. A catalog entry linking the source and authoring documentation.
4. A changeset and regenerated cartridge artifacts where applicable.
